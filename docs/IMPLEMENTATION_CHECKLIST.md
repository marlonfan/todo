# 实现与验收清单

本轮范围：修复 2026-10-08 审查中的其余 10 项问题。用户明确排除日历订阅 token 的权限问题及默认 JWT 密钥问题。

## 修复清单

每项必须完成开发、对应回归检查，再标记完成。

- [x] F01 PostgreSQL JSON 字段支持文本、字节和空值。
- [x] F02 并发任务修改保护版本，不覆盖其他设备的提交。
- [x] F03 增量同步采用提交顺序可靠的游标，覆盖延迟提交及删除。
- [x] F04 任务操作与幂等凭据一起提交；重复、并发和故障重试不重复创建。
- [x] F05 保存、重建、桌面通知、日历导出统一遵守任务提醒策略。
- [x] F06 通知退避不会溢出，超过重试上限后停止自动投递。
- [x] F07 通知处理支持整体超时、取消和有限并发，退出时停止工作。
- [x] F08 退出账号取消桌面通知，阻止异步旧会话重新排定通知。
- [x] F09 Web / Electron 认证失效正确返回登录页，检查未定义变量。
- [x] F10 本地数据库打开失败保留离线编辑和 outbox，不自动删除数据。

## 修复证据

| 项目 | 实现结果 | 回归证据 |
|---|---|---|
| F01 | JSON scanner 接受 pgx 的 string、[]byte 与 NULL | JSON scanner 单测；PostgreSQL JSON 实库往返 |
| F02 | 用户写事务先加锁；UPDATE 比较 revision，不回退到 INSERT | SQLite / PostgreSQL 两个编辑者仅一方成功；另一方版本冲突 |
| F03 | 用户提交有序的 v1 序列游标，变更与删除记录同事务提交 | 延迟提交、第二个写者不能超越、分页、HTTP 更新与删除 |
| F04 | 幂等凭据、结果快照与任务操作一起提交 | 写凭据故障完整回滚；四个并发重复创建只落一条；删除后重试不复活 |
| F05 | 保存、提醒重建、ICS、桌面统一 inherit / none / offset | 账号默认开关 × 三种策略；零偏移；全天时区、夏令时；重复任务实例携带策略 |
| F06 | 移位前限制指数；最大退避 30 分钟；12 次失败后 abandoned | 负数、28、64、极大重试次数；终止后再次扫描不发送 |
| F07 | 6 路并发、父 context 传递、30 秒发送上限、调度整体 5 分钟上限 | deadline 中断；未领取任务保持待处理；取消释放领取；Stop 等待结束且可重复调用；同键去重 |
| F08 | 退出取消已排定和发送中的通知；延迟回调和旧会话失效 | 等待网络时退出、等待 Electron send 时退出、计时器退出；真实 IndexedDB 清理顺序 |
| F09 | 统一 Web / Electron 运行环境与登录跳转；构建执行 no-undef | 两端路由单测；真实浏览器两端认证失效；离线与刷新失败保留会话 |
| F10 | 打开失败不删库；blocked 提示重试；读取 outbox 失败停止同步 | transient open 保留任务/outbox；迟到连接关闭；有离线修改拒绝重建；同步不覆盖缓存 |

验收中补充修复：迁移归一化旧任务 revision 并防止重复回填；任务临时 ID 切换保留正在编辑的草稿、说明会话与待提交状态。浏览器用例强制延迟创建响应后立即编辑，确认最终标题已提交。

发布后 CI 补充修复：后端检查前通过 build.sh 生成内嵌前端文件；任务 ID 切换兼容选择状态与缓存分别渲染的过渡状态，保持详情输入框连接及焦点，避免正在进行的输入丢失。新增真实浏览器节点存续与焦点断言。
