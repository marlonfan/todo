# Todo Native — MyGo Native UI 迁移

使用固定版本 MyGo（9233663736ca）、Lobe MyGo（5b3ecde8b184）和 Go 1.27.3 的独立原生客户端。
界面由 Go 的 github.com/egoist/mygo/ui 与 Lobe 原生组件绘制，窗口只配置 Content: ui.View(...)，没有 HTML、
React、Electron、WebView、JavaScript bridge 或前端构建步骤。

当前是迁移中的可运行版本，尚未达到 Electron 的完整功能对等。

当前源码采用 248 侧栏、44/52 固定逻辑行高、46 单行快捷添加和 420–520 详情栏。既有任务属性自动落盘，标题/描述以 450ms 防抖保存，失焦、切换或关闭前先持久化到本机；新建任务和本次实例复合改期仍显式校验并确认。详情底栏区分本机保存与服务器同步状态。

2026-11-13 开始按真实仓库 Electron 0.1.38 桌面版对齐：暖白/青瓷主题、列表标题前距 92→46、右侧悬停手柄、实底拖动预览与边缘约束、固定顶部属性快捷入口，以及普通/实例描述的原生源码＋同步 Markdown 预览。实时预览不是 Vditor IR/WYSIWYG；当前 MyGo richtext 的 IME 状态可观测性及 Markdown 元信息保留不足，探针证据与未对齐边界见 [本轮报告](artifacts/native-electron-alignment-review.md)。当前新包身份见 [指纹](artifacts/electron-alignment/20261113-round1/fingerprints.json)，签名、镜像及QA关闭后的本机生产窗口启动均已校验；Designer有边界通过，当前源码与体验包已交付。实际Electron离线库42项任务与Native两版按明确业务字段映射比较无差异，提醒17分钟在独立sandbox经界面输入并确认保存；均不代表Electron完整功能对等或通知实际投递。

## 运行

先在仓库根目录启动现有 Go 服务：

    ./build.sh && ./bin/todo-app

再从本目录启动原生客户端：

    make dev

默认服务地址为 http://127.0.0.1:8080，登录页面可以改成已有远端服务地址。
接受带 /api 后缀的地址；已有账号直接登录即可从服务器同步数据。
环境变量 TODO_API_URL 可更改首次登录时的默认地址。

## 构建与预览

    make preview   # macOS 生成本地 ad-hoc 签名的 .app，保留原生 UI inspector
    make build     # 当前平台的生产包；macOS 同时生成 DMG

macOS 预览产物：build/darwin-arm64/Todo Native.app。可直接打开：

    open 'build/darwin-arm64/Todo Native.app'

MyGo 使用系统图形 API 绘制原生 UI，客户端不需要 Node 或 Bun，也不依赖本地
WebView Runtime。Go 命令会自动下载 go.mod 指定的工具链。
Windows/Linux 可以交叉编译；本阶段的运行验证在 macOS arm64 上进行。

## 数据兼容

复用原 Go API 和远端账户，不复制或改动 Electron 的 Chromium 用户数据目录。
生产配置使用独立 bundle ID life.marlon.todo.native，可与 Electron 并行运行。
本地会话和缓存默认保存在系统配置目录中的 mygo-todo 子目录；可通过
TODO_NATIVE_DATA_DIR 指定独立目录。会话文件为 0600，目录为 0700；打包原生应用使用
MyGo Secrets 将会话令牌放入 macOS Keychain、Linux Secret Service 或 Windows Credential
Manager，`session.json` 只保留服务地址和账户元数据。没有系统凭据服务时自动回退到受权限
保护的 JSON，以保持 Linux 精简桌面仍可登录。

Electron 尚未同步的离线编辑不会自动迁移；应先在原客户端完成同步。
本阶段客户端仍连接现有服务，不内嵌或启动另一个后端。

## 离线与冲突处理

任务修改先原子写入本地 cache.json，再尝试发送。任务快照、队列、服务器确认和
临时编号映射写在同一文件内；未保存到磁盘时不会向界面报告保存成功。网络响应
丢失、服务端 5xx 或应用重启后，重试保留相同操作编号与请求内容，复用后端去重收据。
同一任务的后续修改使用前一条确认返回的 revision，避免离线期间猜测版本号。

409 会保留本地意图与服务器版本，阻止该任务后续排队修改；独立任务可继续提交。
在「同步」页面比较后，可显式提交本地版本（使用新的操作编号与服务器 revision），
或确认放弃此任务全部待同步修改。放弃重试不会撤销服务器已接受的操作。
有待同步修改时不能直接退出登录；登录失效可在同步页面重新验证同一账户。

同步页面使用 Lobe 原生概览、状态标签、警告与分组卡片，分别显示等待提交、版本
冲突和需要处理的数量。同一任务被冲突阻塞的后续修改会注明等待前序处理。
版本纵向排列，简览显示标题、描述和状态，并标出存在差异的字段；展开后可核对
完整描述、时间、分类、提醒和重复规则。单次修改单独显示本次意图，系列快照仅
作为背景比较，不伪装成本次实例的修改结果。放弃确认显示将移除的实际操作数量。

登录检查失败会明确提示重新验证，并将密码验证入口移到队列前方；原待同步意图
与操作编号保持不变。验证同一账户成功后继续提交。验证密码不写入本机偏好或队列。
隔离真实窗口专项为 make sync-smoke，最近为 11/11 PASS，覆盖冲突、重试与放弃、依赖阻塞和独立提交、
断网重启、明暗主题，以及登录失效恢复；使用临时账号、数据库、profile 和端口。
截图位于 artifacts/native-lobe-sync-*.png。

任务读取使用 /tasks/sync 的 v1 序号游标，每页 500 条，后台最多长轮询 20 秒，
变更分页继续读取时不等待。游标与任务数据原子保存，重启从已保存的位置继续；
旧缓存首次接入会重建服务器任务快照，但保留离线队列。缺少序号接口的旧服务器
回退到全量读取。分类、账户资料和其他页面仍每 15 秒更新一次，编辑弹窗打开时
暂停这类前台刷新。只有后台长轮询不占用忙碌状态；前台提交与手动刷新仍会暂时
禁用写入控件。

后台读取期间可以继续输入和保存。结果提交前核对本机缓存代次；若已发生本地保存、
任务编号映射、前台刷新或日历缓存更新，则丢弃旧响应并从未前移的游标重读。
原子写盘成功后才更新界面；分页、实例或日历读取失败不会提交部分游标。
重复实例、历史与提醒数据随任务变更一起读取并保存，避免提前推进游标。
已排队的本地修改仍叠加在服务器快照上；未保存草稿保留打开时的 revision，
远端同时编辑时继续产生 409，版本比较保留最初读取内容。正在比较冲突、拖拽
日历、使用任务菜单或确认放弃时，后台结果暂不提交，稍后重读。

make incremental-smoke 最近为 8/8 PASS，使用临时后端、账户、profile 和可控慢响应代理，
覆盖无全量任务扫描的引导、编辑期间接收、慢读取期间保存、迟到响应隔离、真实冲突、
远端删除、重复单次完成和游标重启恢复。
离线完成重复实例后，下一实例需联网从服务端读取；新建的离线重复系列保留为待同步任务。
分类与账户偏好支持本机队列、重启恢复和联网自动提交；头像、密码和 CalDAV 来源凭据
仍要求联网，避免敏感信息写入任务缓存。

## 重复规则与单次描述

新建任务选择重复周期后，可填写间隔和次数（0 表示不限）。星期可填「周一，周五」，
按月/年可填写「第2个周一，最后1个周五」；支持中文或英文逗号分隔，另有工作日/周末快捷填写。
月内日期为 1–31，月份为 1–12，空值不添加限制。各项限制同时生效，不存在的日期会略过。
农历使用现有服务的北京时间算法，可设每隔几年、农历月/日、优先闰月和次数。

次数和结束日期可同时设置，以先到者为准；新设规则的结束日期包含账户时区的整天。
打开已有系列时默认保留完整规则；点击「编辑重复规则」才转换为原生编辑字段。
仅改标题或描述不会重写原有规则，整个系列的日期仍使用原始起点。

打开具体重复实例后，点击「编辑本次描述」记录内容；留空可清空本次描述。
单次描述独立于系列描述，保存使用原始实例日期，而非改期后的显示日期。修改先原子保存到
本机队列，再使用版本号和固定操作编号提交；离线时列表、日历和提醒使用已保存的描述。
编辑单次描述不会改变状态、暂停后续提醒或使整个系列日历消失。

具体实例窗口的「调整本次时间」可以改变开始/结束、全天，或「恢复本次系列时间」。
结束不选即清除；全天结束日期是排他边界。保存和恢复均先进入本机任务队列，可离线
保存、重启恢复与自动同步。原始实例日期与编号不因改期改变；系列起点、其他实例、
本次描述和完成状态保留。恢复仅恢复当前系列规则对应的本次时间。

此功能需要同步升级仓库中的 Todo 后端；专用 PATCH /api/tasks/:id/occurrences/schedule
接受 instance_id、occurrence_date、start_time、end_time、all_day；reset_schedule=true
时由服务器恢复本次的系列时间。后端按当前账户时区校验原始日期确实属于当前重复
规则，使用 If-Match、固定操作编号及同一事务内的去重收据更新。没有修改旧的
PATCH /schedule 和 PUT 时间字段语义。旧服务端不支持时请求被拒绝并保留本机
队列，可在升级后显式重试；客户端不会回退到会修改整个系列的旧接口。

后端展开同时按原始日期和改期后的有效时间读取例外，原始范围不再重复显示，
新范围可包含原系列起点之前或结束之后的移入实例。列表按实际时间选择下一待办，
本机提醒即时采用离线改期；服务端默认自动提醒的重排和周期滚动使用实例的时间
与全天设置。活动记录按原始实例日期标注时间变更。
同一系列混合定时/全天实例时，服务端按账户时区和自定义早间时间计算后的提醒
时间选择下一项，保存时重排与周期重建使用同一规则。

## CalDAV 与日历导出

侧栏的 CalDAV 页面连接现有服务上的来源。添加时填写名称、地址、用户名和密码，

## 原生本机提醒

原生后台调度器每秒检查任务，以账户时区计算提醒时间。普通任务以开始时间为准；
全天任务使用账户的 default_morning_time，再减去提前分钟数。支持跟随账户、不提醒、
单任务提前量（0–10080 分钟）。沿用服务器约定：单任务显式提前量的在线保存需先配置
默认通知渠道，可在原生侧栏「通知渠道」中配置。账户默认提醒
与本机开关独立；本机开关不影响服务器通知渠道。

每次同步额外缓存未来 38 天的日历实例，覆盖未来 30 天提醒与最多七天提前量；
因此较早的实例仍逾期时，后续重复实例也能触发。离线使用缓存日程，普通离线新建任务
也能提醒。完成/取消/跳过/删除会撤销待提醒项；离线编辑重复系列时暂停该系列，待服务器
重新展开后恢复。退出应用会停止调度，重新打开或电脑唤醒仅补发最近 15 分钟的提醒。

发送记录独立保存在 reminders.json，包含服务/账户、任务与实例，原子写入。离线新建
任务的提醒身份在映射服务器编号后保持不变。先记录预留，再交给系统，成功后记录 submitted；
失败释放预留，一分钟后重试。重启保留发送去重；若恰好在预留成功与系统接收之间崩溃，
该次可能漏发，这是优先避免重复发送的取舍。记录损坏或写入失败时暂停发送并在设置页提示。

macOS 首次发送会请求系统授权，拒绝或超时有中文提示；未授权时不记录成功。
通知点击按当前服务与账户打开对应任务/单次实例；同名任务不会串账户。自动化测试使用
仅存在于 e2e 构建的文件接收端，覆盖调度与持久化，不代表系统已显示横幅。
实际横幅展示和系统冷启动点击仍需在打包应用获授权后人工验收。

## 原生分类管理

分类页使用 Lobe 概览、标签和操作卡片，编辑器提供即时预览、六种预设颜色与
自定义 #RRGGBB 输入。名称 1–50 字符、表情最多 16 字符；空表情和颜色保存为

编辑仅改变草稿，保存成功后刷新关联任务；取消清空草稿，不改动原分类。
删除确认说明仅移除分类及其关联，任务和其他分类保留。分类创建、编辑与删除先原子
保存至 cache.json 的 category_outbox，再在本机生效；断网重启恢复名称、表情、颜色
与任务关联。初次本机写盘失败保留编辑器草稿，不采用未保存值。同步页展示分类操作、
等待/拒绝状态、失败原因与重试/放弃；有分类待同步时阻止退出登录。

新建分类使用独立负数编号，本机立即可选。联网后先提交分类新建/编辑，将服务器
正数编号、别名和未发送任务的关联原子落盘，再提交任务；分类删除等待引用它的
任务操作处理完成后执行。未确认编号不会发送到任务 API。放弃本机新分类或删除
尚未送出的新分类只解除该临时关联，保留任务及其余分类。其他设备删除编辑器中
选中的分类时，保存会清除失效选择并要求检查后再次保存，保留其余任务草稿。

专用 POST /api/categories/sync 要求 X-Client-Op-Id；分类操作与回执在同一服务端
事务中保存，创建响应丢失或本机确认写盘失败后跨重启重放，不重复创建。已送出但
结果不明确的请求保持原编号和内容，后续编辑独立排队；未发送和已明确拒绝的修改
可以合并。同名拒绝保留关联任务，独立任务继续；修改分类名后可继续同步。旧服务
不支持该端点时保留队列并显示升级说明，不回退到不能保证重放安全的普通创建接口。
分类元数据没有版本号，保存会提交当时明确填写的名称、表情与颜色；尚未提供多设备

## 原生 AI、提示词与描述草稿

从底部「设置」进入「AI 与提示词」，可添加、编辑、搜索、删除提示词，选择提示词发起问答。
工作区采用 Lobe 原生卡片、搜索栏与分段切换；提示词和问答历史分别呈现，历史显示
完成状态、时间和回复摘要，并明确搜索只覆盖已加载记录。配置、提示词编辑和回复
弹窗支持明暗主题，内容可滚动，保存、取消、复制、停止和采用操作固定在底部；
900×600 窗口下，长输入与长错误不会把这些操作挤出窗口。修改输入会清除旧错误，
取消编辑不会修改账户内容。配置取消或关闭后清空包含 API Key 的内存草稿。
AI 配置复用账户现有的协议、基础地址、模型 ID、API Key、系统提示词、使用者背景
和任务背景开关。支持 OpenAI 兼容 Chat Completions 与 Anthropic Messages，
由本机直接访问所配置的模型服务；保存配置不会调用模型。请求只携带模型专用密钥，
不携带 Todo 登录凭据，不跟随跳转。协议兼容采用现有客户端的接口，不依赖 Electron。

回复支持流式显示、停止、Lobe 原生 Markdown 预览、只读源码和复制，不自动加载远程图片。
模型返回的独立思考字段及 think/thinking 标签与正文分开；每次打开新问答、历史或
描述草稿都恢复预览并折叠思考内容，不沿用上一问答的展开状态。本客户端不会要求模型提供内部推理。
停止或连接中断会保留已收到的正文，长度截断会标为不完整；请求最长三分钟，响应
最多 8 MB，正文与思考字段各限制 50 万字符。模型 HTTP 错误只显示状态与中文说明，
不回显可能包含敏感信息的错误响应。

有正文的提示词问答自动保存到服务端，记录完成/停止/不完整状态；支持每页 50 条
的真实游标分页、搜索已加载历史、查看只读快照和删除确认。删除提示词保留历史快照。
历史创建接口没有幂等收据，失败时不会自动重试；保存结果未确认时先复制回复，
再关闭窗口刷新历史确认，避免产生重复记录。配置、提示词和历史操作需要联网，
断网保留当前窗口输入，不写入任务离线队列。

任务编辑器与「编辑本次描述」提供 AI 描述草稿。输入以当前编辑中的内容为准，默认
不发送其他任务；需账户允许且本次明确勾选才附带背景。背景使用本机缓存，最多
160 个任务、约 26 KB，每个文本字段最多 520 字符。生成后可替换或追加到草稿，
采用后的内容按任务类型保存：既有任务/实例文本走自动保存，新建任务仍显式创建。生成期间若原描述已变化，会保留草稿并拒绝覆盖。
描述 AI 结果不自动进入提示词问答历史。

API Key 在输入框中掩码显示；账户配置由现有 Todo 后端保管，原生端不新增密钥文件
或把配置/问答写入 profile。编辑期间与发请求时临时读取到内存，关闭、保存成功或
退出登录清空配置草稿。采用并保存的描述属于任务数据，会进入正常的本地任务缓存。

专项命令 make ai-smoke，最近验证为 18/18 PASS。使用临时账号、SQLite、profile
及本地模型 HTTP 夹具，驱动真实 Native UI 检查配置、提示词 CRUD、OpenAI/Anthropic
流、停止、截断、敏感错误隔离、描述采用与明确保存、单次实例草稿隔离、背景授权、历史分页/删除、
断网草稿、本机文件无密钥、明暗主题、取消不保存和思考折叠状态重置。不会调用真实模型或产生 API 费用；实际供应商账户的
连通性及不同模型的输出质量仍需使用者配置后检验。单元测试另覆盖 JSON 非流回复、
跨块思考标签、输出上限、终止事件、取消请求和拒绝跳转。

## 当前原生界面预览与交互验证

任务页以可拖动的紧凑列表与右侧详情组成；小窗口使用可返回的单栏详情。
